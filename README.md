# Discord Rich Presence with music from your browser!

# IMPORTANT
For this to properly work you need webnowplaying and webnowplaying CLI installed, theres where to download it from:
**WNP:** github: https://github.com/keifufu/WebNowPlaying; firefox: https://addons.mozilla.org/en-US/firefox/addon/webnowplaying/; chrome: https://chromewebstore.google.com/detail/webnowplaying/jfakgfcdgpghbbefmdfjkbdlibjgnbli

**WNP CLI:** github: https://github.com/keifufu/WebNowPlaying-CLI/releases/tag/3.0.0-alpha.6

# SETUP
1. install WebNowPlaying (WNP) AND enabled CLI in extension menu
2. install WNP CLI **AND ADD IT TO PATH, MARK "ADD TO PATH" IN THE INSTALLER**
3. grab .exe file from releases or clone/download daemon.bat and song_metadata.py from my repository (compiled release: https://github.com/g17zg/music-DiscordRPC/releases/tag/compiled)
4. create an application on https://discord.com/developers/applications, select name and avatar for your application, they will be used as avatar in rich presence and name of application.
5. start the .exe or .py file, depending on what you installed and enter the application id in prompt displayed.
6. enjoy :3

**IMPORTANT: if you choose to use not compiled files (.py and .bat) you will need to install required modules uses "pip install", see list of modules in first lines of code of song_metadata.py**
*not sure if you need to install modules for .exe too*
